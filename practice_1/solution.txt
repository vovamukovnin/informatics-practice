Ответы:

1. Ответ на вопрос 1
GitHub — это платформа для хостинта и совместной разработки IT-проектов на основе системы Git. Основные цели:
Хранение кода в удалённых репозиториях
Организация командной работы через механизмы ветвления и pull requests
Отслеживание задач и ошибок через Issues
Автоматизация процессов сборки и тестирования (CI/CD)
Создание портфолио разработчика

2. Ответ на вопрос 2
Репозиторий — это хранилище данных проекта, содержащее не только текущие файлы, но и полную историю их изменений. В контексте Git репозиторий включает рабочую директорию, индекс и базу объектов. Назначение:
Сохранение всех версий файлов проекта
Обеспечение возможности отката к предыдущим состояниям
Координация работы нескольких разработчиков

3. Ответ на вопрос 3
Приватный репозиторий — репозиторий с ограниченным доступом, просмотр и участие в разработке доступны только авторизованным пользователям. Отличия:
Публичный: виден всем пользователям интернета, способствует open-source развитию
Приватный: доступ контролируется владельцем, используется для коммерческих и приватных проектов

4. Ответ на вопрос 4
Ветка (branch) — это независимая линия разработки в репозитории. Механизм ветвления позволяет:
Изолировать разработку новых функций от стабильной версии
Параллельно вести несколько направлений работы (фичи, багфиксы, эксперименты)
Безопасно тестировать изменения перед интеграцией в основную ветку
Реализовывать различные модели workflow (Git Flow, GitHub Flow)

5. Ответ на вопрос 5
Главная ветка (main) — это первичная ветка репозитория, содержащая стабильную, рабочую версию продукта. Значение:
Служит источником для развёртывания (деплоя) в production
Является точкой интеграции всех изменений из feature-веток
Требует особых практик защиты (protected branch, code review)
Правильный выбор и защита main обеспечивает стабильность проекта
